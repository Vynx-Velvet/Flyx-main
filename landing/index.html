Make it yours

From zero to Flyx
in a few commands.

Node.js 20+ is all you need. The guided setup handles configuration, creates your first account, and gets out of the way.

Quick start~5 min
01git clone https://github.com/Vynx-Velvet/Flyx-main.git
02cd Flyx-main && npm install
03npm run cli:link && flyx setup
04flyx start
